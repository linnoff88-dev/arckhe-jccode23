🔬 Los dos poderes de la ads-skill

La ads-skill es un caso poco común de skill con dos poderes complementarios: análisis y generación. Son inseparables en el workflow: el análisis alimenta la generación.

🔬 Poder 1: análisis

  • →Recibe una URL o un archivo de video UGC
  • →Extrae fotogramas a 2fps mediante ffmpeg
  • →Transcribe audio con Whisper
  • →Identifica segmentos HOOK/SHOW/PROOF/CTA
  • →Genera un informe de análisis viral

🎬 Poder 2: Generación

  • →Recibe 4 inputs: imagen/audio/video/actor
  • →Enruta al modelo ideal (4 opciones)
  • →Ejecuta dialogue gate (confirma el costo)
  • →Llama a la API de Arcads y consulta el estado periódicamente
  • →Devuelve la URL del video generado

🤖 Enrutamiento inteligente entre 4 modelos

En lugar de que el usuario tenga que elegir el modelo, la skill abstrae esa decisión con una lógica de enrutamiento clara. La tabla de decisión está en prompting/model-routing.md.

Tabla de enrutamiento

Sora 2 Videos de más de 30 s o con estilo cinematográfico Largo / cinematográfico

Lógica de enrutamiento en prompting/model-routing.md
# Model Routing — ads-skill

## Árvore de decisão

if has_speech AND needs_lip_sync:
    → Seedance 2.0  # padrão para UGC com ator

elif has_reference_frame AND visual_consistency_critical:
    → Veo 3.1  # frame inicial travado

elif duration_seconds > 30 OR cinematic_style:
    → Sora 2  # longo / cinematográfico

elif silent AND visual_only:
    → Kling 3.0  # silencioso / estético

else:
    → Seedance 2.0  # fallback padrão

## Rationale
Seedance: único com lip sync confiável para português
Veo: quando frame 0 é crítico (ex.: unboxing específico)
Sora: quando a narrativa precisa de mais de 30 segundos
Kling: produto sem locutor (ex.: product shots, natureza)

💡 Abstracción = poder para el usuario

El usuario no necesita saber que existen 4 modelos. Describe lo que quiere ("necesito un UGC con el actor João hablando sobre el producto") y la skill elige el modelo correcto. Ese es el valor real de una skill bien diseñada: complejidad oculta, poder accesible.

⚠️ Reglas estrictas de ads-skill

Tres hard rules protegen las tres cosas más importantes: la integridad del contenido, el presupuesto y la seguridad de las credenciales.

1

NUNCA parafrasees la transcripción: solo verbatim

La transcripción del video UGC se extrae palabra por palabra. La skill no puede reescribir, resumir ni "mejorar" el texto.

Por qué es inviolable:

Los anuncios UGC virales tienen un timing específico: una pausa en el segundo 1.3s, una inflexión en el 2.7s. Una paráfrasis cambia la duración de las palabras y rompe la sincronización con el frame. Lo que funciona en 2 segundos puede durar 3.2s y hacer que el espectador se vaya.

2

SIEMPRE ejecutar el dialogue gate antes de generar

Antes de cualquier llamada a la API de Arcads, presenta un resumen completo: actor elegido, modelo, costo estimado en créditos, duración estimada.

Por qué es inviolable:

Una generación de 15s en Seedance cuesta ~8 créditos Arcads. Un loop accidental o un input incorrecto puede consumir 100 créditos ($50-200) en segundos. El gate es el único freno antes del gasto real.

3

NUNCA registres la API key en ningún output

Los scripts leen $ARCADS_API_KEY del entorno. La clave nunca aparece en logs, en la salida del terminal, en archivos de depuración ni en ninguna otra salida.

Por qué es inviolable:

Los scrapers encuentran en minutos las API keys expuestas en los logs. Una clave de Arcads comprometida permite que terceros generen videos en tu cuenta — con cargos ilimitados hasta que te des cuenta.

⏱️ El framework UGC de 15 segundos

Todo anuncio UGC viral de 15 segundos sigue la misma estructura de 5 segmentos. La ads-skill identifica y extrae automáticamente cada uno.

✓ Cada segmento en la práctica

  • HOOK (0-2s): sorpresa, pregunta provocadora, contradicción, algo raro que está pasando
  • SHOW (2-6s): demostración real del producto, beneficio visible en acción
  • PROOF (6-11s): número específico ("3 kg en 7 días"), testimonio, antes/después
  • CTA (11-14s): una sola acción — "haz clic en el enlace de la bio", "compra ahora"

✗ Errores fatales por segmento

  • HOOK débil: logo del producto en los primeros 2s (desplazamiento inmediato)
  • SHOW incorrecto: imagen de stock, no una demostración real
  • PROOF vago: "funciona muy bien" sin un número
  • CTA múltiple: dos verbos de acción ("haz clic Y comparte")

💡 Tu próxima skill: copiar la estructura, adaptar el dominio

La ads-skill es una plantilla de referencia para cualquier skill que integre una API externa con varios modelos. La estructura check → analyze → gate → upload → generate → status funciona para:

  • • Síntesis de audio (ElevenLabs, Murf, Play.ht)
  • • Procesamiento de documentos (análisis de contratos, extracción de datos)
  • • Cualquier API con polling asíncrono
