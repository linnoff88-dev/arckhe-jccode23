🖥️ Qué es la terminal

O terminal es un programa que recibe comandos de texto y los ejecuta en el sistema operativo. Es la interfaz más directa y potente de una computadora — anterior a las interfaces gráficas y mucho más eficiente para la automatización.

🖥️ Dónde encontrar la terminal

🍎 macOS

Spotlight (⌘+Space) → "Terminal" o instala el iTerm2 para una mejor experiencia.

🐧 Linux

Ya incluye terminales (gnome-terminal, konsole, xterm). Atajo: Ctrl+Alt+T en la mayoría de las distribuciones.

🪟 Windows

Usa WSL2 (Windows Subsystem for Linux) para un entorno Unix real. PowerShell funciona, pero tiene diferencias.

💡 Consejo: el prompt te indica dónde estás

El prompt user@mac ~/projetos/meu-app $ tiene tres partes: usuario@máquina, directorio actual (~ = home), y $ indicando que puedes escribir. Lee el prompt antes de escribir cualquier comando.

📂 Carpetas y rutas

El sistema de archivos es un árbol: una raíz, con carpetas dentro de carpetas, dentro de carpetas. Saber dónde estás y cómo hacer referencia a los archivos es la habilidad básica #1 del terminal.

🌳 Estructura típica de directorios

/ ← raíz (root) — absoluto
├── home/
│ └── user/ ← ~ (carpeta personal del usuario)
│ ├── projetos/
│ │ └── meu-app/ ← estás aquí
│ │ ├── src/
│ │ └── package.json
│ └── Downloads/
# Ruta absoluta: /home/user/projetos/meu-app
# Ruta relativa (desde ~/projetos): ./meu-app
# Subir un nivel: ../ (va a ~/projetos)

✓ Ruta absoluta

  • /home/user/projetos/app
  • /etc/nginx/nginx.conf
  • /usr/local/bin/node

Empieza con / — funciona desde cualquier lugar

→ Ruta relativa

  • ./src/index.ts
  • ../config/env.json
  • ../../outro-projeto/

⚡ Comandos esenciales

No necesitas memorizar 200 comandos Unix. Con 10 comandos puedes navegar, crear, mover e inspeccionar cualquier proyecto con Claude Code.

📖 Referencia rápida — 10 comandos esenciales

pwd # print working directory — ¿dónde estoy?
→ /home/user/projetos/meu-app
ls # list — ¿qué hay aquí?
ls -la # con detalles y archivos ocultos
→ src/ package.json .gitignore node_modules/
cd carpeta # change directory — navegar
cd .. # subir un nivel
cd ~ # volver a home
mkdir nome # make directory — crear carpeta
mkdir -p a/b/c # crea una jerarquía completa
cat archivo # ver el contenido del archivo
cp orig dest # copiar archivo
mv orig dest # mover/renombrar archivo

Cómo usa Claude Code estos comandos en el día a día

→

ls — explorar la estructura

El agente usa ls para entender el proyecto antes de actuar. Es lo primero que hace en las sesiones nuevas.

→

mkdir -p — crear estructura

Para crear features, el agente crea las carpetas necesarias antes de escribir los archivos.

→

mv — refactorización

Mover archivos a una nueva estructura de carpetas durante las refactorizaciones es algo cotidiano.

🔌 Qué es una CLI

Una CLI (Command-Line Interface) es un programa que controlas escribiendo comandos de texto. Git, npm, Python, Docker y Claude Code son CLI. Entender la anatomía de un comando de CLI es una habilidad que sirve para todas ellas.

🔍 Anatomía de un comando CLI

# Estructura general:
programa [subcomando] [--flags] [argumentos]
# Ejemplos reales:
git commit -m "mensaje"
npm install --save-dev typescript
claude --dangerously-skip-permissions -p "tarea"
# Ayuda siempre disponible:
claude --help
git --help
npm help install

✓ Buenas prácticas de CLI

  • ✓Usa siempre --help antes de adivinar
  • ✓Autocompletado con Tab — presiona Tab para autocompletar
  • ✓Las flechas ↑↓ recorren el historial de comandos
  • ✓Ctrl+C cancela el comando actual

✗ Trampas de la CLI

  • ✗Copiar un comando de internet sin leerlo
  • ✗Ignorar los mensajes de error
  • ✗Usar sudo sin necesidad
  • ✗Escribir comandos en la carpeta equivocada

📦 Instalar herramientas

Para usar Claude Code, necesitas instalar Node.js y el paquete npm. Entender administradores de paquetes es esencial: son la forma estándar de instalar CLIs en cualquier sistema.

Instalando Claude Code — paso a paso

1

Instalar Node.js

# macOS (Homebrew)
brew install node
# Linux (Ubuntu/Debian)
curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -
sudo apt-get install -y nodejs
2

Verificar la instalación

node --version # debe mostrar v18+
npm --version # debe mostrar 9+
3

Instalar Claude Code

npm install -g @anthropic-ai/claude-code
# verificar:
which claude # debe mostrar la ruta
claude --version

💡 Qué es el PATH

Cuando escribes claude, el shell busca el ejecutable en las carpetas enumeradas en la variable PATH. Si aparece "command not found", es porque la carpeta global de npm no está en el PATH. Solución: export PATH="$PATH:$(npm root -g)/../.bin".

🔒 Seguridad en la terminal

La terminal tiene poder real sobre el sistema. Un comando incorrecto puede borrar archivos irrecuperables, exponer credenciales o instalar software malicioso. Estas reglas sencillas evitan el 99% de los problemas.

⚠️ Comandos que NUNCA copies sin entender

rm -rf / ← borra TODO el sistema
rm -rf ~ ← borra todos tus archivos
curl URL | bash ← ejecuta código desconocido
sudo chmod -R 777 / ← elimina la seguridad del sistema
> archivo.conf ← ¡borra el contenido del archivo!

Regla: si no puedes explicar qué hace un comando, no lo ejecutes.

✓ Buenas prácticas de seguridad

  • ✓Usa .env para secretos y nunca hagas commit de este archivo
  • ✓Verifica qué vas a borrar antes con ls
  • ✓Prefiere mv a la Papelera en lugar de rm
  • ✓Lee con atención los mensajes de confirmación (y/n)

✗ Errores de seguridad comunes

  • ✗Confirmar claves de API o contraseñas en git
  • ✗Usar sudo indiscriminadamente
  • ✗Ejecutar scripts de terceros sin revisar
  • ✗Dejar variables de entorno en el historial

💡 Seguridad con Claude Code

Claude Code puede ejecutar cualquier comando Bash. Configura el settings.json con una denylist para comandos destructivos que nunca quieres que ejecute automáticamente. Así tienes autonomía con seguridad.

"deny": ["Bash(rm -rf:*)", "Bash(git push --force:*)"]
