🤖 Qué es un agente de IA

Uno agente de IA es un programa que percibe el entorno, razona sobre lo que debe hacer y ejecuta acciones para alcanzar un objetivo — repitiendo este ciclo hasta completarlo. Esto es radicalmente distinto de un chatbot que solo responde una pregunta y se detiene.

✓ El agente lo hace

  • ✓Lee 20 archivos para entender el proyecto
  • ✓Ejecuta las pruebas y corrige lo que se rompió
  • ✓Itera hasta completar la tarea
  • ✓Crea, edita y elimina archivos reales

✗ Lo hace el chatbot

  • ✗Responde una vez y espera una nueva pregunta
  • ✗Genera código, pero no lo ejecuta
  • ✗No sabe si el código funciona
  • ✗No tiene acceso al sistema de archivos

💻 ¿Por qué la terminal?

La terminal no es solo una ventana negra intimidante. Es el punto de acceso directo al sistema operativo — archivos, procesos, red, compiladores, servidores. Un agente que vive en la terminal tiene poder real para transformar código en resultados.

💡 ¿Por qué no una interfaz gráfica?

Las interfaces gráficas son lentas de automatizar, dependen de la resolución de pantalla y cambian con las actualizaciones. La terminal es estable, permite crear scripts y es universal: funciona en cualquier servidor remoto, CI/CD o contenedor Docker.

  • •Velocidad: crear 50 archivos con 1 comando vs. hacer clic 50 veces
  • •Composición: el pipe de comandos crea flujos imposibles en la GUI
  • •Acceso remoto: SSH conecta el agente a cualquier servidor

📁 Qué lee, escribe y ejecuta

Claude Code no es un modelo flotando en la nube. Tiene herramientas concretas que interactúan con el sistema real: leen archivos, editan código, ejecutan comandos, buscan patrones. Cada acción es visible en la terminal.

🛠️ Herramientas nativas de Claude Code

Read Lee el contenido de cualquier archivo del repositorio
Editar Hace sustituciones exactas en archivos existentes
Write Crea archivos nuevos o sobrescribe por completo
Bash Ejecuta cualquier comando shell: npm, git, python, etc.
Glob Lista archivos por patrón: **/*.ts, src/**
Grep Búsqueda de texto/regex en archivos del proyecto

✓ Puede hacerlo

  • ✓Crear y modificar cualquier archivo de texto

✗ No se puede (sin plugins)

  • ✗Ver imágenes o PDFs (solo texto)

🎯 Casos de uso reales

Claude Code no es un juguete de demostración. Se usa en proyectos reales de producción para tareas que llevarían horas de trabajo manual al día.

📊 Dónde destaca Claude Code

  • →Refactorización a escala: renombrar una función en 80 archivos, actualizar imports, garantizar la coherencia
  • →Migración de API: actualizar llamadas obsoletas de una biblioteca a la nueva versión
  • →Generación de pruebas: cubrir las funciones existentes con pruebas unitarias y de integración
  • →Depuración: leer el stack trace, localizar el bug, proponer y aplicar la corrección
  • →Boilerplate: crear la estructura del proyecto, configurar las herramientas, escribir el README

💡 Consejo: el marco mental adecuado

Piensa en Claude Code como un desarrollador júnior muy rápido que nunca se cansa. Ejecuta bien tareas bien definidas, pero necesita contexto claro. Cuanto mejor describas lo que quieres, mejor será el resultado.

⚡ Chatbot vs. agente: la diferencia práctica

La diferencia no es filosófica: es pragmática. Cambiar la forma de usar la herramienta cambia radicalmente el resultado. Aquí está el contraste en el día a día:

💬

Modo chatbot (ineficiente)

"Escríbeme una función para validar email" → copia el código → lo pega en el editor → descubre que no funciona → vuelve al chat → pide una corrección → repite 5 veces.

🤖

Modo agente (eficiente)

"Agrega validación de email al formulario en src/auth.ts y escribe pruebas para ella" → el agente lee el archivo, escribe el código, ejecuta las pruebas y hace ajustes hasta que pasen. Tú revisas el resultado.

⚠️ Trampa común

Las personas que vienen de ChatGPT tienden a hacer preguntas a Claude Code en lugar de delegar tareas. Resultado: respuestas mediocres. Reformula «¿cómo hago X?» como «haz X en el archivo Y».

Verificar el resultado, no cada paso

🚀 Primer contacto

La mejor forma de entender un agente es verlo funcionando. Aquí está el flujo del primer contacto: desde la terminal en blanco hasta la primera tarea completada.

💻 Sesión inicial típica

# Abre la terminal y navega hasta tu proyecto
$ cd meu-projeto
# Inicia Claude Code
$ claude
# Aparece el prompt interactivo
> Lee el README y dime qué hace este proyecto
# El agente lee el archivo y responde
● Read README.md
● Este proyecto es un servidor Node.js que...

💡 Qué observar en la primera sesión

Cuando el agente trabaja, verás líneas como ● Read src/index.ts e ● Bash: npm test. Este es el registro de herramientas en tiempo real: cada línea es una acción concreta en tu sistema.

Presta atención a este registro durante las primeras sesiones. Es el "razonamiento visible" del agente.
