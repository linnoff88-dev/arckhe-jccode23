🎬 Dos estudios de caso reales

El curso no se queda en la teoría. Analizas dos artefactos de producción:

  • 🧩ads-skill — una skill que analiza anuncios virales y los recrea con Arcads. Muestra la anatomía completa de una skill.
  • 🏗️ClaudeOS — un dashboard personal de IA con scanner, skill /dream, cron y versionado. Muestra un proyecto real de largo plazo.
